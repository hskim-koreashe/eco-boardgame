# 프롬프트 카드

프롬프트는 그대로 붙여 넣어도 되고, 단체 이름이나 숫자만 바꿔도 됩니다. 한 번에 다 요구하지 말고 **한 문장씩 추가**하는 것이 잘 됩니다.

설치가 막히면: [Claude Code 설치(git) & GitHub 저장소 연결 가이드](https://app.notion.com/p/Claude-Code-git-GitHub-f140f783b157822eb9c501c822e5e86c) (화면 캡처 포함)

---

## 카드를 넣기 전에 — 에이전트는 루프·하네스·스킬로 일합니다

| 개념 | 무엇인가 | 카드에서 |
|---|---|---|
| **루프** | 프롬프트 → 계획 → 도구 실행(파일 읽기·쓰기, 명령 실행) → 결과 확인 → 다시 계획을 목표가 될 때까지 반복. 에러를 읽고 고치는 것도 한 바퀴 | 카드 하나에 요청 하나. 한 문장씩 추가하면 루프가 짧고 정확해집니다 |
| **하네스** | 루프를 감싸는 실행 환경: 폴더, 규칙 파일(CLAUDE.md), 참고자료(uploads), 허락 범위(모드), 모델, 커넥터. Claude Code 앱이 곧 하네스 | 카드 0이 하네스 설정입니다(CLAUDE.md, 작업 기준) |
| **컨텍스트** | 에이전트가 지금 기억하는 것: 대화 + CLAUDE.md + 읽은 파일. 새 세션이면 비워집니다 | 오래 남을 규칙은 대화가 아니라 CLAUDE.md에 |
| **스킬** | 반복 절차·전문 지식을 문서로 묶어 두고 필요할 때 꺼내 따르는 것(업무 매뉴얼) | 카드 0-1의 카파시 스킬. 옵션: Superpowers |
| **도구·커넥터** | 에이전트의 손. 파일·터미널·브라우저에 GitHub·Notion 등을 커넥터로 붙임 | GitHub 커넥터를 붙이면 "리포지터리 만들고 푸시해 줘"가 한 문장 |

우리가 할 일은 루프에 좋은 입력을 주는 것입니다. 작은 요청 하나, 결과를 눈으로 확인, 에러는 그대로 붙여 넣기.

## 카드 0. 준비 (한 번만)

**0-1. CLAUDE.md 만들기** — 세션에 프로젝트 폴더를 연결한 뒤 먼저 넣습니다. Claude가 카파시 스킬(좋은 코딩 습관 네 원칙)을 작업 규칙 파일로 만듭니다.

```
https://github.com/multica-ai/andrej-karpathy-skills 저장소의 CLAUDE.md 내용을 그대로 이 폴더의 CLAUDE.md로 만들어 줘.
```

**0-2. 작업 기준 알려주기**

```
이 폴더의 index.html을 기준으로 작업할 거야. 파일은 index.html 하나만 쓰고, 외부 라이브러리는 CDN으로만 불러와.
데이터는 https://archivelabedu.github.io/ecoarchive-impact2026/data/cards.json 을 fetch로 읽어.
카드의 image 값은 상대경로라서 앞에 https://archivelabedu.github.io/ecoarchive-impact2026/games/ 를 붙여야 해.
한국어로, 초록색 계열로, 모바일에서도 보이게 만들어 줘.
```

## 카드 1. 공통 실습 — 뒤집기 짝 맞추기

```
카드 뒤집기 짝 맞추기 게임을 만들어 줘.
cards.json에서 type이 "event"인 카드 8장을 무작위로 뽑아, 각 카드의 front(사건 이름)와 year(연도)로 카드 16장을 만들어 4×4로 섞어 놓아.
두 장을 뒤집어 사건과 연도가 짝이면 그대로 두고 아래에 back(설명)과 url 링크를 보여 줘. 짝이 아니면 1초 뒤 다시 뒤집어.
뒤집은 횟수를 표시하고, 다 맞히면 축하 메시지와 다시 시작 버튼.
```

이어서:
- `카드 뒷면에 image가 있으면 사진을 작게 보여 줘`
- `6×6으로 늘리고 type이 "org"인 단체 카드도 섞어 줘 (단체 이름 ↔ 설립 연도)`
- `2인용으로 바꿔서 번갈아 뒤집고 점수를 따로 세 줘`
- `타이머를 추가해 줘`

## 카드 2. 선택 ① 에코폴리 (주사위 말판)

```
주사위 말판 게임을 만들어 줘.
cards.json에서 type이 "year"인 카드를 year 순으로 정렬해 1982~2025 말판 44칸을 만들어(한 줄 11칸).
두 명이 번갈아 주사위(1~6)를 굴려 이동해. 도착한 칸의 연도 카드에 events가 있으면 "이 해에 시작된 사건은?" 4지선다,
없으면 "이 해의 특징 키워드는?"(keywords 첫 번째가 정답, 다른 해의 키워드 3개가 오답) 4지선다.
맞히면 count를 100으로 나눈 만큼(최소 1, 최대 40) 점수. 결승선에 먼저 닿으면 게임 끝, 점수 높은 사람이 승리.
```

## 카드 3. 선택 ② 타임라인 카드배치

```
타임라인 게임을 만들어 줘.
cards.json에서 type이 "event"와 "org"인 카드를 섞어 8장을 뽑아. 1장은 가운데 줄에 놓고 시작하고 7장은 손패로 줘.
손패 카드를 클릭해 고른 뒤, 줄의 카드 사이에 있는 "+" 버튼을 누르면 그 자리에 끼워 넣어.
year 순서가 맞으면 줄에 남고, 틀리면 카드가 사라지고 정답 연도를 알려 줘.
손패가 없어지면 끝. 줄에 남은 카드 수가 점수.
```

이어서: `카드에 image가 있으면 작은 사진을 보여 줘` · `사건만 / 단체만 고르는 선택 메뉴` · `손패 수를 5·7·10장에서 고르게`

## 카드 4. 선택 ③ 인물 스무고개

```
인물 스무고개 퀴즈를 만들어 줘.
cards.json에서 type이 "person" 또는 "org"이고 hints가 2개 이상인 카드 10장을 뽑아.
처음엔 hints의 첫 번째만 보여 주고 "힌트 더 보기" 버튼으로 하나씩 열어.
보기는 정답 1개와 같은 type의 다른 카드 3개 이름으로 4지선다.
힌트를 1개만 보고 맞히면 40점, 2개 30점, 3개 20점, 4개 10점. 정답을 고르면 back(설명)과 url 링크를 보여 줘.
10문제 끝나면 총점.
```

이어서: `image가 있으면 흐리게 보여 주다가 정답 후 선명하게` · `인물만 / 단체만 선택`

## 카드 5. 선택 ④ 컬렉션 룰렛

```
룰렛 게임을 만들어 줘.
cards.json에서 type이 "collection"인 카드 10장을 뽑아.
"돌리기" 버튼을 누르면 CSS로 원판이 3초간 회전하고, 멈추면 카드의 keywords 5개가 하나씩 튀어나와.
어느 컬렉션인지 4지선다(정답 1 + 다른 컬렉션 3)로 고르게 하고, 맞히면 10점.
정답 뒤에 back(소개)과 count(기록 수), url 링크를 보여 줘. 10문제 끝나면 총점.
```

## 카드 6. 선택 ⑤ 에코 도블

```
사진 짝 짓기 게임을 만들어 줘.
https://archivelabedu.github.io/ecoarchive-impact2026/data/photo_cards.json 을 읽어 (image 앞에 https://archivelabedu.github.io/ecoarchive-impact2026/games/ 를 붙여).
artist가 서로 다른 사진 4장을 뽑아 격자로 보여 주고, 아래에 4명의 artist 이름을 섞어서 버튼으로 놓아.
사진을 누른 뒤 이름을 누르면 짝이 이어지고, 4쌍이 되면 "확인" 버튼으로 채점해. 맞은 사진은 초록 테두리, 틀린 사진은 주황.
채점 뒤 사진 위에 title·year·loc를 보여 주고 url 링크. 5라운드, 한 쌍 5점.
```

이어서: `모드를 골라서 artist 대신 region(장소)이나 event(사건)로도 짝 지을 수 있게` · `사진 크기를 키워 줘`

## 카드 7. 자주 쓰는 수정 프롬프트

- `모바일에서 깨져. 화면이 좁을 때 한 줄에 2장씩 보이게 해 줘`

- `제목을 "OOO"으로 바꾸고 맨 위에 한 줄 설명을 넣어 줘`

- `점수를 화면 오른쪽 위에 항상 보이게`
- `정답을 맞히면 짧은 효과음 대신 카드가 살짝 커지는 애니메이션`
- `코드를 더 단순하게 정리해 줘. 기능은 그대로`
- `index.html 한 파일로 합쳐 줘`
- `커밋하고 푸시해 줘`

## 카드 8. 막혔을 때

- 페이지가 안 열림 → Settings › Pages: Branch main, 폴더 /(root). 파일 이름이 `index.html`인지. 1~2분 기다리기.
- 고쳤는데 그대로 → Shift + 새로고침.
- 카드가 안 나옴 → 데이터 주소를 브라우저에 직접 열어 JSON이 보이는지. 이미지는 `games/` 경로를 붙였는지.
- 에러가 보임 → 브라우저에서 F12 → Console의 빨간 글씨를 복사해 Claude에게 "이 에러를 고쳐 줘".
- 너무 복잡해짐 → 처음 프롬프트로 돌아가 다시 시작(코드는 git에 남아 있으니 괜찮습니다).
